# Learning Log: From Technical Writer to AI-Enabled Documentation Engineer

A 26-week plan to learn programming foundations, core computer science concepts, APIs, LLMs, RAG, agents, and MCP, at about 5 hours a week.

**Started:** YYYY-MM-DD
**Target finish:** YYYY-MM-DD

## How to use this repository

1. Check off each task (`- [x]`) as you finish it.
2. Save each problem set and project in the `projects/` folder.
3. Add a short weekly note in `weekly-notes/`, using the template at the end of this file.
4. Commit at least once a week. Your commit history is your progress record.

### Folder structure

```
learning-log/
├── README.md          ← this plan and tracker
├── weekly-notes/      ← week-01.md, week-02.md, ...
└── projects/          ← problem sets, mini-projects, capstone
```
